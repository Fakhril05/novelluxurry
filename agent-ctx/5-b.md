# Task 5-b: Enhance Blog Page & Cart Drawer

## Task 1: Blog Page Enhancements (BlogPage.tsx)

### Changes Made:
1. **Gradient image placeholders** — When blog posts have no image, a `BlogImagePlaceholder` component renders a dark gradient background (5 palette variants) with the category's initials in gold, using `getCategoryGradient()` for deterministic color assignment per slug.

2. **Featured card spans 2 columns** — The `FeaturedCard` component now uses `col-span-1 sm:col-span-2` to visually span 2 columns. The parent grid uses `sm:grid-cols-2 lg:grid-cols-3` so the featured card takes 2/3 width on large screens.

3. **Featured badge** — Added a `Sparkles` icon badge showing "Artikel Pilihan"/"Featured Article" on the featured card's image.

4. **Read time badge on featured card** — Added a prominent gold-tinted read time badge above the title.

5. **Load More button gold theme** — Changed from `variant="outline"` to solid gold fill with `bg-[#D4AF37]` and shadow. Added `BookOpen` icon and `ArrowRight` icon.

6. **Hover animations** — BlogCard now uses `whileHover={{ y: -6 }}` (up from -1) with `hover:shadow-2xl hover:shadow-[#D4AF37]/8` for stronger lift + gold-tinted shadow. FeaturedCard has `whileHover={{ y: -4 }}`.

7. **Empty category filter state** — New `EmptyFilterState` component with `SearchX` icon in a decorative circle, descriptive text, and a "Clear Filter" button that resets the category filter.

8. **Blog detail improvements**:
   - Author meta wrapped in a styled card with border and muted background
   - Added "Published on" date label
   - Added view count badge (random for demo)
   - Gold read time badge in detail
   - Related articles now have read time badges on cards and author avatars
   - Related articles use staggered animation (`delay: 0.7 + idx * 0.1`)
   - Category badge on detail image uses gradient placeholder when no image

9. **Hero section** — Book icon now wrapped in a rounded-2xl gold-tinted container.

10. **Removed unused imports** — Cleaned up `FALLBACK_IMAGES` map and `getBlogImage` function, replaced with `getBlogImageOrPlaceholder` helper.

## Task 2: Cart Drawer Enhancements (CartDrawer.tsx)

### Changes Made:
1. **Format badge with color coding** — Added `getFormatColor()` and `getFormatIcon()` helpers that return distinct colors per format: gold for Hardcover, indigo for Ebook, emerald for Paperback. Each cart item now shows a styled `Badge` with the format icon and name.

2. **Clear Cart with confirmation** — Added `AlertDialog` from shadcn/ui with a "Clear Cart" trigger in the items header. Shows confirmation dialog with cancel and red delete action. On confirm: clears cart, resets voucher state, shows toast.

3. **Item subtotal per line** — Shows unit price × quantity when quantity > 1. Always shows the line total (unitPrice × quantity) as the primary price. When quantity is 1 and there's a discount, shows original price as strikethrough.

4. **Improved empty cart state** — Larger 128px illustration with triple-nested circles (gradient from 5% to 15% gold opacity), Package icon, small ShoppingBag badge. Decorative floating dots around the illustration. Spring animation on mount.

5. **Enhanced checkout button** — Taller (h-12), bolder font, includes total amount, `ShoppingBag` icon with scale animation on hover, gold shadow that intensifies on hover.

6. **Secure checkout text** — Added `Shield` icon with "Pembayaran Aman & Terenkripsi" / "Secure & Encrypted Payment" text below checkout button.

7. **Items header** — Shows item count ("3 items") with a clear cart link in a sub-header between the main header and scroll area.

8. **Improved delivery estimate** — Rounded-xl container with a Truck icon in a gold-tinted rounded-lg box, bolder text styling, better spacing.

9. **Better voucher display** — Added `Tag` icon next to active voucher text.
